# Master Timeline

> A complete chronological record of every significant event in your case. Add events as they happen. Link to detailed notes in `/timeline/`.

---

## How to Use This Timeline

Each entry should include:
- **Date** — exact date where possible, approximate if not
- **Event** — what happened, in one sentence
- **Type** — colour-coded category (see legend below)
- **Evidence** — link to the document or note that proves it
- **Event ID** — unique identifier (see [[_system/analysis-framework]])

### Event Type Legend
- 🔵 **Court** — hearings, orders, filings
- 🟢 **Contact** — visits, calls, messages, refusals
- 🔴 **Incident** — allegations, police, safety concerns
- 🟡 **Professional** — reports, assessments, referrals
- 🟣 **Communication** — letters, emails, SMS threads
- ⚪ **Administrative** — costs, service, procedural
