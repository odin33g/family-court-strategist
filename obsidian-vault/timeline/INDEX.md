# Timeline Events

> Detailed notes for individual events. Each event gets its own file using the [[_templates/incident|incident template]].

---

## How to Use

1. For each significant event, create a new note using the incident template
2. Name it: `YYYY-MM-DD_short-description.md`
3. Fill in the YAML frontmatter (date, type, event_id, people, issue)
4. Write the detailed account
5. Link it back to the [[MASTER-TIMELINE]]

---

## Event Categories

| Category | Event ID Prefix | Examples |
|----------|----------------|---------|
| Incidents | EVT-### | Allegations, police calls, safety concerns |
| Communications | COM-### | Key messages, calls, email chains |
| Court Orders | ORD-### | Interim orders, final orders, variations |
| Legal Letters | LTR-### | Solicitor advice, settlement offers |
| Affidavit Claims | AFF-### | Specific claims from sworn documents |
| Patterns | PAT-### | Recurring behaviours identified |
| Strategy | STR-### | Your tactical notes and plans |
