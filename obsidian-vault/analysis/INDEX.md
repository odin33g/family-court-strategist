# Analysis Hub

> This section contains your strategic analysis tools — the engine that turns raw documents into case arguments.

---

## Documents

- [[EVIDENCE-MATRIX]] — Master tracker: every major claim mapped against evidence, strength rated
- [[CROSS-DOCUMENT-ANALYSIS]] — Contradiction engine: timeline conflicts, story evolution, credibility issues
- [[COINCIDENCE-MAP]] — Suspicious timing alignments between events

---

## How to Use

### Step 1: Process Every Document
When you add a new document to the vault, run it through the [[_system/analysis-framework|13-point protocol]]. This extracts facts, claims, evidence, contradictions, and opportunities.

### Step 2: Update the Evidence Matrix
For every major claim in the case, update the [[EVIDENCE-MATRIX]]:
- What does each professional say about it?
- What independent evidence exists?
- What contradicts it?
- Rate the strength: PROVEN / DISPUTED / UNRESOLVED / DISPROVEN

### Step 3: Cross-Reference
Use the [[CROSS-DOCUMENT-ANALYSIS]] to find:
- Where the same event is described differently in different documents
- How someone's story has changed over time
- Where professional opinions conflict
- Credibility vulnerabilities you can use

### Step 4: Map Timing
Use the [[COINCIDENCE-MAP]] to identify suspicious timing:
- Did something happen right before or after a court event?
- Is there a pattern of escalation around key dates?
- Do contact refusals correlate with legal milestones?
